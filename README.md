# QuestStack

QuestStack is a Meta Quest 1 root and bootloader unlocking project.

Using the GhostLock privilege escalation chain and CVE-2021-1931 ABL/fastboot vulnerability, QuestStack provides a method to gain root access on latest Quest 1 firmware, replace the invulnerable abl.img with a vulnerable one, and unlock the device bootloader.

The project combines Quest firmware research, root access, ABL modification, and fastboot unlocking into a single workflow looking to gain full control over Quest 1 hardware.
